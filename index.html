🚧 Flagship Project · In Progress
Databricks Restaurant Data Platform
// Data Engineering · Medallion Lakehouse on Azure Databricks + Unity Catalog

End-to-end medallion data platform on Azure Databricks and Unity Catalog, ingesting real-time restaurant order events from Azure Event Hubs and batch dimensional data from Azure SQL Server via Lakehouse Federation. Raw data lands in a governed landing zone, gets transformed through bronze and silver layers with dbt-databricks, and will surface business-ready gold aggregations for dashboards and AI-powered sentiment analysis on customer reviews — orchestrated end to end via Databricks Workflows.

  • Hybrid ingestion: Event Hubs streaming (DLT) for high-frequency orders, Lakehouse Federation batch for slow-changing dimensional data — latency matched to actual business need, not defaulted to streaming
  • Unity Catalog governs the full lakehouse: landing/bronze/silver/gold schemas plus a foreign catalog for federated Azure SQL access
  • dbt-databricks owns bronze → silver → gold: built-in testing, lineage, and incremental merge models
  • Orchestration: single Databricks Workflow — SQL ingestion task → dbt task, scheduled daily
